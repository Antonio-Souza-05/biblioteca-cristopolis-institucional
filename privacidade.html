Política de Privacidade

Sistema de Gerenciamento da Biblioteca de Cristópolis

Esta política descreve como o Sistema de Gerenciamento da Biblioteca de Cristópolis poderá tratar informações relacionadas à administração do acervo, aos leitores e à realização de cópias de segurança.

1. Finalidade do sistema

O sistema tem como objetivo auxiliar na organização dos livros, no cadastro de leitores e no controle de empréstimos, devoluções e reservas.

2. Dados tratados

Conforme as funcionalidades utilizadas, o sistema poderá armazenar informações cadastrais dos leitores e funcionários, bem como registros de empréstimos, devoluções e reservas.

3. Utilização das informações

Os dados são utilizados para a execução das funcionalidades administrativas da biblioteca. O acesso deve ser restrito às pessoas autorizadas pela instituição responsável.

4. Integração com o Google Drive

O sistema utiliza a API do Google Drive, mediante autorização de uma conta Google, para criar e armazenar cópias de segurança do banco de dados.

A permissão solicitada permite gerenciar arquivos utilizados pelo próprio aplicativo. O acesso não exige a autorização das contas Google dos leitores.

5. Segurança e armazenamento

Os backups têm como finalidade permitir a recuperação das informações em caso de falhas ou perda de dados. Medidas adicionais de segurança, incluindo criptografia e controle de acesso, devem ser implementadas antes do uso com dados pessoais reais.

6. Compartilhamento de dados

As informações não são destinadas à comercialização. O armazenamento de backups no Google Drive envolve o processamento necessário à prestação desse serviço.

7. Direitos dos titulares

Os titulares dos dados poderão solicitar informações sobre o tratamento de seus dados pessoais e exercer os direitos previstos na Lei Geral de Proteção de Dados Pessoais (LGPD), conforme aplicável.

8. Contato

Para dúvidas sobre o projeto ou sobre esta política, entre em contato pelo e-mail: biblioteca.cristopolis26@gmail.com .

9. Atualizações

Esta política poderá ser atualizada para refletir mudanças no funcionamento do sistema e nas medidas de proteção de dados.
